BUILT DIFFERENT

Beautiful to explore.
Clear when it matters.

A dynamic, morphing interface should make the product memorable, never hide what a system action will do.

01 / MOTION

Fluid, alive and optional.

Ambient gradient shapes shift naturally. Desktop page transitions soften navigation. Turn motion off any time, and the website respects reduced-motion preferences.

02 / CONTROL

Preview. Confirm. Restore.

Registry tweaks keep a local record of prior values. Presets are fully previewable. Diagnostic actions always show the command before they execute.

RUN IT YOUR WAY

Start with the source.

This is a developer preview, not a signed Windows release. Download and inspect the script before running it; a reviewed version can be executed locally.

Recommended: inspect first

irm https://win.marceli.dev/win -OutFile .\MarceliWin.ps1

Open the file with Notepad, then run it with Windows PowerShell 5.1. Changes only happen after you select and confirm them.

Convenience launcher

irm https://win.marceli.dev/win | iex

Remote execution is convenient but carries risk. Only use it after reviewing the script and trusting the endpoint.
